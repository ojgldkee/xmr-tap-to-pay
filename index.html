Privacy

Privacy-first defaults

No analyticsNo Google Analytics, Meta Pixel, ad SDKs, or fingerprinting scripts.
No application IP logsThe XMR Tap backend code does not store client IP addresses or User-Agent strings.
No third-party QR CDNThe QR library is served locally from this repository instead of loaded from a tracking-capable CDN.
Private quote proxyIn production, XMR/USD quotes are fetched server-side so the merchant browser does not contact the price provider directly.
Important: hosting providers and network infrastructure may still retain connection logs outside this app’s control. XMR Tap itself does not intentionally collect them.
